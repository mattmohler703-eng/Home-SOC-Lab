# Home SOC Lab

## Overview

This project documents the design, deployment, and maintenance of a Home Security Operations Center (SOC) using Wazuh, Kali Linux, Windows 11, VirtualBox, and a TP-Link network infrastructure.

The purpose of this lab is to gain hands-on experience with security monitoring, endpoint management, troubleshooting, and SOC operations.

## Lessons Learned

During development of the Home SOC environment, network infrastructure changes resulted in Wazuh server IP address changes. Endpoint connectivity was verified and restored through troubleshooting and configuration validation.

This project continues to evolve as additional endpoints, detections, and security monitoring capabilities are added.
