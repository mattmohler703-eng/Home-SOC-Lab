# Home SOC Lab

## Project Overview
This project documents the creation of a Home Security Operations Center using Wazuh, Kali Linux, Windows, VirtualBox, and home network devices.

## Goal
The goal of this lab is to build hands-on cybersecurity experience by deploying a basic SOC environment, monitoring endpoints, documenting assets, and practicing security analyst workflows.

## Tools Used
- Wazuh
- Kali Linux
- Windows
- VirtualBox
- PowerShell
- Linux Terminal
- GitHub

## Lab Environment
- HP Envy host machine
- Wazuh server virtual machine
- Kali Linux virtual machine
- Windows endpoint
- Verizon Fios router
- Home network devices

## Skills Demonstrated
- SIEM deployment
- Endpoint monitoring
- Network inventory
- Linux basics
- Windows administration
- Troubleshooting
- Technical documentation

- Wazuh manager installed
